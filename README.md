# ✅ Habit Tracker

A clean, simple, and responsive **Habit Tracker** built using **HTML, CSS, and JavaScript**.
It helps you track daily habits, monitor consistency, view monthly progress, and build better routines.

## ✨ Features

* ✅ Track daily habits
* 📅 Month and year navigation
* 📊 Daily and monthly progress
* 🔥 Habit streak tracking
* 📈 Weekly progress overview
* 🏆 Best habit indicator
* ➕ Add new habits
* ✏️ Rename existing habits
* 🗑️ Delete habits
* 🌙 Light & Dark mode
* 💾 Automatic data saving using Local Storage
* 📱 Responsive design
* 🚫 Future dates cannot be marked as completed

## 🛠️ Built With

* **HTML5** — Structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Functionality and habit tracking logic
* **Local Storage** — Saves habit data in the browser

## 🚀 How to Use

1. Open the Habit Tracker.
2. Add or rename habits according to your routine.
3. Click the checkbox for each habit you complete.
4. Your progress is automatically saved.
5. Check your daily, weekly, and monthly progress.
6. Keep your streak going! 🔥

## 💾 Data Storage

Habit data is stored locally in the browser using **Local Storage**.

This means your progress remains saved even after refreshing the page or shutting down your computer, as long as the browser's site data is not cleared.

## 🎯 Purpose

The goal of this project is simple:

> **Consistency over perfection.**

Instead of trying to be perfect every day, this Habit Tracker helps you focus on building consistent habits over time.
